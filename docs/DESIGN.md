# Дизайн и решения

Дата начала: 2026-09-29.

## 1. Зачем проект

AlecaFrame (Overwolf) удобен, но интерфейс только на английском, код закрыт — перевести нельзя
(Overwolf перезаписывает файлы при обновлении, часть логики в нативном плагине, лицензия запрещает).
Рассмотренный open-source аналог **WFHelper** (github.com/WFHelper/WFHelper, MIT, Electron+Svelte)
имеет i18n (`src/i18n/*.json`, en/de/zh, русского нет), но получает инвентарь чтением памяти игры +
токен сессии → запрос к API DE. Этот метод мы сочли рискованным (см. §4). Поэтому — своё приложение.

Код WFHelper можно читать как референс (MIT), в частности `ipc/overlay/scan.ts` (сканер наград).

## 2. Функционал

Легенда риска: ⚪ нулевой · 🟢 низкий · 🟡 средний · 🔴 высокий (не делаем).

### A. Справочник (офлайн-данные) ⚪
- A1 База предметов: варфреймы, оружие, моды, компаньоны, характеристики.
- A2 Где что падает: таблицы дропа, реликвии, ротации.
- A3 Литейная: рецепты, дерево ресурсов.
- A4 Гайды (свой контент).
- A5 Конструктор билдов: моды, аркейны, шарды, расчёт характеристик. Самая трудоёмкая часть.
- A6 Каталог билдов игроков (свой сервер, аккаунты) — позже, вместе с сайтом.

### B. Живой мир (публичные API) ⚪
- B1 Циклы, разломы, вторжения, Баро, арбитражи, вылазки, Архонт.
- B2 Уведомления («появился нужный разлом», «прилетел Баро»).

### C. Рынок warframe.market ⚪
- C1 Цены, ордера, история.
- C2 Копировать фразу для личного сообщения в буфер (в игру НЕ вставляем сами).
- C3 Управление своими ордерами через API warframe.market (без массовой автоматизации — их правила).

### D. Рядом с игрой (пассивно) 🟢
- D1 `EE.log`: статистика забегов, определение миссии, триггеры событий.
- D2 **Оверлей наград за реликвии** с ценами (главная фича).
- D3 Оценка ривена по скриншоту (OCR).
- D4 Ривен из ссылки в чате (OCR).
- D5 Оверлей = отдельное прозрачное окно поверх игры, клики проходят насквозь.
  Игра в режиме «окно без рамки».

### E. Инвентарь — ОТЛОЖЕН
Ждём ответ DE (`DE_REQUEST.md`). Варианты по безопасности:
1. Приложение внутри Overwolf (режим разработчика, для себя) и их модуль данных Warframe —
   самый безопасный, т.к. это массовый канал. Не проверено: даёт ли Overwolf доступ к
   инвентарю Warframe dev-приложениям.
2. Ручной импорт / без инвентаря — текущий выбор.
3. 🔴 Чтение памяти + nonce + запрос к API DE (как WFHelper) — не делаем без явного «да» от DE.
4. 🔴 Имитация мобильного приложения DE — не делаем (логин/пароль/2FA в нашем коде,
   обратная разработка, серверная аналитика ловит чужой отпечаток клиента).

### Никогда
Макросы/автоклики/автотрейд/отправка чата, модификация файлов игры, запись в память,
внедрение в процесс, любое боевое преимущество.

## 3. Ключевые решения

| Решение | Почему |
|---|---|
| Десктоп, а не сайт | `EE.log`, снимок экрана и оверлей требуют доступа к ПК. Сайт позже на том же UI. |
| **Tauri 2**, не Electron | Висит рядом с игрой постоянно: ~10–15 МБ установщик и ~50–100 МБ RAM против ~150 МБ и 200–400 МБ у Electron. |
| Не Overwolf (пока) | Без инвентаря он не нужен; модерация стора, реклама, обязательный клиент. Вернёмся, если захотим инвентарь (вариант E1). |
| SvelteKit (SPA, adapter-static) + Svelte 5 + TS | Лёгкий, быстрый, WFHelper на нём же. Tailwind НЕ взяли: хватает scoped CSS + токены в `src/app.css`, меньше зависимостей. |
| Данные: `warframe-public-export-plus` | Официальный Public Export + словари DE на 15 языках, **есть `dict.ru.json`** → термины как в русском клиенте. Дополнительно WFCD `warframe-items` (MIT), официальные drop tables. |
| Данные не вшиты в установщик | Отдельный пакет, обновляется при патче игры без переустановки. |
| База v0.1: один `static/data/db.json` (~1 МБ) в памяти | Наград/реликвий/наборов ~1500 записей — поиск в памяти мгновенный, SQLite пока лишний. Вернуться к SQLite, когда добавим все предметы/моды (A1). |
| Поиск: свой, `src/lib/db.ts` | Нормализация (ё→е, без пунктуации), каждое слово запроса — префикс слова названия, в любом порядке; 1 опечатка на слово ≥4 букв. Ранжирование: набор > часть > реликвия, активные выше хранилища. |
| Главная навигация — `Ctrl+K` | Один поиск «Сарина прайм» → дроп, цена, билды. Удобнее вкладок. |
| Живой мир: api.warframestat.us | Работает (проверено 29.09). Параметр `?language=ru` названия нод НЕ переводит → переводим сами через `ExportRegions` + `dict.ru.json`. |
| Цены: api.warframe.market v2 | `/v2/orders/item/{slug}/top`, цена = дешёвый продавец онлайн. Кэш 5 мин, очередь ~3 запроса/с. `gameRef` у них = наш uniqueName → slug сопоставляется точно. |
| Сеть через `tauri-plugin-http` | Запросы идут из Rust — нет проблем с CORS. Разрешённые домены в `src-tauri/capabilities/default.json`. |
| Иконки: `https://browse.wf` + путь из экспорта | Публичный хостинг игровых картинок (см. README warframe-public-export-plus). |
| OCR: встроенный Windows OCR (`Windows.Media.Ocr`) | Бесплатный, быстрый, умеет русский (нужен языковой пакет). Не нагружает GPU рядом с игрой. |
| Снимок экрана: Windows Graphics Capture | Системный способ, без внедрения в процесс игры. |
| `EE.log`: Rust `notify`, дочитывание хвоста | Без опроса таймером. Путь: `%LOCALAPPDATA%\Warframe\EE.log`. |

## 4. Сканер наград за реликвии — как делаем быстрее конкурентов

Схема у AlecaFrame/WFHelper: строка «Got rewards» в `EE.log` → **фикс. ожидание 650 мс** →
снимок → OCR → сопоставление → цены. Итого ~1–1,5 с. AlecaFrame в русском клиенте, по наблюдению
пользователя, работает (их доки пишут «soon» — устарели). WFHelper требует английский клиент.

Наши улучшения:
1. Вместо фиксированных 650 мс — поток кадров после триггера, дешёвая проверка «анимация
   карточек закончилась» (стабилизация яркости в зоне названий) → сразу OCR. −300…500 мс.
2. Не зависеть от задержки записи лога: в миссии разлома (известно из лога) раз в ~100 мс
   проверять несколько характерных пикселей экрана наград. Первый сработавший триггер побеждает.
3. Цены/дукаты/«в хранилище» по всем наградам реликвий (несколько сотен) держим в памяти
   заранее, фоновое обновление. В момент награды сети нет.
4. OCR только полос с названиями, ч/б + увеличение, 4 куска параллельно.
5. Нечёткое сопоставление только со словарём наград реликвий (сотни, не тысячи) → устойчиво
   к кривому OCR, в т.ч. кириллица/латиница. **Поддержка русского клиента** — через `dict.ru.json`.
6. Карточки показываются по мере готовности.

Время подумать важнее миллисекунд: выделенный лучший выбор («Бери это: 45 пл»), правило выбора
настраивается (платина / дукаты / собираю набор), подсказка ещё в лобби разлома.

Первым делом — **замерочный стенд**: видео экранов наград + отметки времени `EE.log`,
реальные тайминги анимации, лога и OCR на разрешении пользователя. Оптимизировать по фактам.

## 5. Дизайн интерфейса
Тёмная тема, свой стиль (не копия игрового UI), настоящие игровые иконки предметов с публичных CDN.
Вкус пользователя: модерн-минимализм, без тяжёлых «корпусов» и нарисованных иконок.
