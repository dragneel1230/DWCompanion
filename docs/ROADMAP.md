## v0.1 — Фундамент (проверяется без запуска игры)
Цель: приложение запускается, всё на русском, по любому предмету видно «где падает и сколько стоит».
- [x] Окружение: Node LTS, pnpm, Rust (MSVC уже есть — VS 2022 Community)
- [x] Каркас Tauri 2 + SvelteKit/Svelte 5 + TS, тёмная тема, окно приложения
- [x] Конвейер данных: `warframe-public-export-plus` → компактная база (имена ru/en, реликвии
      и их награды, дукаты, «в хранилище») → `static/data/db.json` (SQLite позже)
- [x] Поиск `Ctrl+K` с нечётким совпадением (русские и английские названия)
- [x] Карточка предмета (+ набор, + реликвия с выделением самой дорогой награды): иконка, название ru/en, из каких реликвий падает, дукаты
- [x] Цена warframe.market в карточке (кэш)
- [x] Страница разломов: на русском, таймеры, обычные / Стальной путь / Бури

Статус 2026-09-29: код написан, типы проверены. **Ждёт проверки пользователем** (`pnpm tauri dev`).
Известное: «Sambir Cloud» (Railjack) нет в словаре DE — остаётся по-английски.
